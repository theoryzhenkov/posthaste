# LOC / context-bloat audit — apps/mcp, apps/site, tools, docs, root artifacts

Scope: `apps/mcp/`, `apps/site/`, `tools/`, `docs/`, root-level generated artifacts
(`openapi.json`, `asyncapi.json`), the 9 `review-*.md` + `context.md` +
`design-wasm-replica.md` scratch files, `nix/`, justfiles, `setup.sh`, config.
This is a **LOC-reduction / AI-context-bloat** audit, not a correctness review.
**No files were edited.** All findings verified against the tracked tree (`jj file list`).

Method note: every "generated" file below was confirmed by tracing its generator
(generator command quoted per-finding). Every "stale" doc was confirmed absent from
the published `mkdocs.yml` nav and/or describing already-shipped work.

---

## Executive summary

The single biggest source of AI-context bloat here is **committed-but-generated
artifacts** — ~19.2k lines of machine output that an agent loads as if it were
source. None of it should be *deleted* (the web/mcp apps build without a Rust
toolchain precisely because these are committed), but all of it should be
**marked generated so it is excluded from AI context** (e.g. `linguist-generated`
in `.gitattributes`, a `.aiexclude`/context-ignore, and/or `.prettierignore`,
which already lists some of them).

The second source is **scratch/ephemeral docs that are tracked but not published**:
the 9 root `review-*.md` files + `context.md` + `design-wasm-replica.md` (~2.8k
lines of one-shot audit output) and `docs/eph/` (4.45k lines, 25 files, *not* in
the mkdocs nav, many describing work that has since shipped).

Note: the task brief's `docs/stale/` (24 files) **no longer exists** — it was
deleted 2026-06-27 (`review-fat-legacy.md:29` "RESOLVED"). Only dangling prose
references to it remain inside `review-fat-legacy.md` itself.

## TOTAL & top 5

**Estimated AI-context reduction: ~26,650 lines** (≈19,200 by marking generated
files non-context + ≈7,250 by deleting/archiving stale scratch docs + ≈200 source),
with **no product behavior change** (generated files stay in git; deleted docs are
unpublished scratch).

### Top 5 ranked by impact-per-risk

1. **G1+G2 — context-exclude the two `schema.gen.ts` (10,380 lines).** Pure
   mechanical openapi-typescript output, regenerable, zero risk. Biggest single win.
2. **G3 — context-exclude `openapi.json` (7,715 lines).** Generated by a
   drift-gated cargo test; agents never need to read it raw.
3. **D12 — archive `docs/eph/` (4,454 lines).** Unpublished; mostly shipped-work
   designs superseded by durable specs.
4. **D1–D11 — delete the root `review-*.md` + `context.md` + `design-wasm-replica.md`
   (2,797 lines).** One-shot audit/design scratch cluttering the high-signal repo root.
5. **G4+G5+G6 — context-exclude wasm glue + `endpoints.md` + `asyncapi.json` (1,093
   lines).** All confirmed generated; trivial to add to the ignore set.

### Implementation hint (one change covers bucket (a))

Add to `.gitattributes` (alongside the existing `*` rule):
```
openapi.json                          linguist-generated=true
asyncapi.json                         linguist-generated=true
apps/mcp/src/schema.gen.ts            linguist-generated=true
apps/web/src/api/schema.gen.ts        linguist-generated=true
apps/web/src/runtime/wasm/*.js        linguist-generated=true
apps/web/src/runtime/wasm/*.d.ts      linguist-generated=true
docs/api/endpoints.md                 linguist-generated=true
```
and mirror the same list in whatever context-ignore the agent harness honors
(`.aiexclude` / `.prettierignore` already covers some). This is the highest
leverage, lowest-risk action in the whole audit.
