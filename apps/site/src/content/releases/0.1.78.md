## Drafts edit in place

### Fixes

- **Editing a draft updates it instead of making a copy.** Reopening a saved
  draft and changing it used to leave the original behind and create a new draft
  each time. Drafts now carry a stable identity, so an edit updates the same
  draft in place — no more duplicates piling up as you revise. Existing drafts
  are adopted automatically the first time you edit them.
