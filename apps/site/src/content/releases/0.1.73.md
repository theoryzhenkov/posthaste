## One source of truth for the message list

The message list now renders entirely from the engine's view of your mailbox —
the same server-folded state that already powers the open message and its
conversation. Scrolling loads more mail in place, and pending changes like flags
and moves show up from one place instead of a separate copy kept in the UI.

### Under the hood

- Removed the last of the renderer's parallel optimism: the list, detail, and
  conversation all reflect engine state directly, so what you see and the synced
  mailbox can no longer drift apart. This also deletes a chunk of now-unused
  cache-patching code.
