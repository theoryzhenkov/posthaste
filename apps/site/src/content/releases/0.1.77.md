## OAuth setup + draft fixes

### Fixes

- **Google (OAuth) account setup completes.** After approving access, setup was
  failing with a "client_secret is missing" error while exchanging the sign-in
  code for a token. The credential is now included in the build, so OAuth
  account setup finishes and the account is added.
- **Drafts save on providers without a configured sender identity.** Saving a
  draft no longer requires the provider to expose a sender identity (a draft
  carries only its From address), so drafts persist even when the provider's
  identity list is empty. Sending still requires a sender identity configured
  with the provider.
