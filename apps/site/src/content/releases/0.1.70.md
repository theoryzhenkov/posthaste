## Offline actions, rebuilt

Archiving, moving, flagging, deleting, and sending are now **local-first**: the
change shows up instantly and is synced to the server in the background, so the
app stays responsive and these actions work even while you're offline.

### Fixes

- **Actions could get stuck and stop syncing.** A message action that hit a
  "providers state diverged" error would wedge the outbox — flags, moves, and
  deletes stopped reaching the server, and folders like Archive could stop
  loading new mail. The action queue was rebuilt so a single conflict can no
  longer block everything behind it; conflicting changes now re-sync on their
  own instead of parking.
- **Local state could drift from the server.** Optimistic changes are now an
  overlay on top of the synced mailbox rather than an in-place edit, so an
  action that's dropped or fails always reverts cleanly to the server's truth —
  no more half-applied state lingering after a failed sync.

### Improvements

- Sidebar and smart-mailbox counts update immediately to match pending actions.
- Sending is queued and retried: you can send while offline and it goes out on
  reconnect. A send interrupted mid-flight is never sent twice.
