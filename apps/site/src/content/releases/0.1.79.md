## Live updates and reliable changes

### Fixes

- **The message list updates as things happen.** Archiving or moving a message,
  a new message arriving, and deletions now refresh the open list immediately,
  instead of only after you switched mailboxes and back.
- **A change that the server rejects is undone, not left showing.** If a flag,
  read, archive, or move can't be saved, the view now reverts to the real state
  (alongside the error notice) instead of continuing to show the change as if it
  had succeeded.
- **Folder and sidebar counts update when a message is deleted.** Unread/total
  counts no longer lag behind after a delete until the next sync.
