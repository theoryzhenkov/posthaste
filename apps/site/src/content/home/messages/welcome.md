I wanted a mail client that treated my mail as mine: kept on my machine, in an open format, behind an interface I could build on. I wanted email to be fast, easy, integrated into my workflows. Nothing like this existed, and so Posthaste puts a documented API in front of lean, optimised runtime; comes as configurable distributed modules for power users who want to host their runtime remotely; and is fully OSS;

Posthaste is the best client I've ever used. I hope the same will be the case for you.
